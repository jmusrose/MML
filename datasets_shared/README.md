# Shared Datasets

Put dataset files used by multiple project versions here. The training
entrypoints now default to these paths:

- `nyud2_trainvaltest/`
- `sunrgbd/`
- `Food101/`
- `MVSA_Single/`
- `CREMA-D/`
- `mosi.pkl`
- `mosei.pkl`

The large data files under this directory are ignored by git.
